Connected and healthy

Connections & resilience

  • ✓MongoDB — 10 s connect / server-selection timeouts, pool of 50, compound and unique indexes created at startup (including TTL indexes).
  • ✓Gemini — 60 s timeout, connection limits, retry on 429, circuit breaker, and fallback to rule-based classification.
  • ✓Apify — server-side run timeout plus a local watchdog; runs are aborted on shutdown.
  • ✓Stripe — real Checkout API call (20 s timeout); webhooks verified by signature with timestamp tolerance; idempotent processing.
  • ✓Webhook signing — HMAC-SHA256 for outbound payloads and for inbound mock and Razorpay webhooks (constant-time compare).
  • ✓Credentials — no hard-coded secrets in app/; secrets come from the environment, and logs redact keys and tokens.

Pipelines & platform

  • ✓Search pipeline — URL search → Apify → pages / posts / comments → Gemini → scored leads → round-robin assignment. Tested end to end.
  • ✓Durable queue — leases, heartbeats, crash recovery and cancellation (MongoDB).
  • ✓Tenant isolation — every scoped route rejects other organizations' IDs (86 tests).
  • ✓Partner program — application → approval → referral → commission → wallet → payout, with refunds, clawbacks, fraud flags and an activity log.
  • ✓Security — bcrypt, lockout, enforced 2FA, CSRF origin check, security headers, revocable sessions with idle timeout.
  • !Not exercised — live Gemini, Apify, Stripe and SMTP calls. These need real credentials, so they were mocked at the network boundary.
